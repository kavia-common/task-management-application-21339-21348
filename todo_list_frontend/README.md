# Ocean Professional Todo List (React)

A modern, minimalist Todo List single-page app with blue (#2563EB) and amber (#F59E0B) accents. Users can add, edit, complete, filter, and remove tasks — all client-side.

## Features
- Add tasks via input + Enter or Add button
- Edit task inline (double-click, press Enter to save, Esc to cancel)
- Complete/uncomplete tasks, filter by All / Active / Completed
- Clear completed tasks
- Theme toggle: Light/Dark (persisted)
- LocalStorage persistence (no backend)
- Ocean Professional design: rounded corners, subtle shadows, smooth transitions, subtle gradients

## Scripts
- `npm start` — run dev server
- `npm test` — run tests
- `npm run build` — production build

## Styling
All theme styles are in `src/App.css`. Primary color is blue `#2563EB`, accent amber `#F59E0B`. Adjust CSS variables at the top for customization.
